# Examples

Working examples that exercise agent-guard end-to-end.

| Example | Language | Demonstrates |
| ------- | -------- | ------------ |
| [`strands-tool-authz/`](strands-tool-authz/) | TypeScript | Strands Agents tool-call authorization via the AuthZEN HTTP PDP |
| [`rust-embedder/`](rust-embedder/) | Rust | Mount the AuthZEN router inside an existing axum app via `agentguard_server::build_router` |

Each example is a self-contained runnable project. See the README inside
each subdirectory for prerequisites, setup, and a runnable command.
